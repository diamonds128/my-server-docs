## 安装

<details>
<summary><strong>Windows</strong></summary>

1. 访问[MCDL](https://mc.minebbs.com/)  
2. 系统选项选择Windows  
3. 找到 `1.20.31` 或 `1.20.3101.0`（我们也兼容 `1.20.30` ）  
4. 点击下载，如果无法访问就选择其他下载通道  
5. 安装 `.Appx`  

</details>

<details>
<summary><strong>Android</strong></summary>

1. 访问[MCDL](https://mc.minebbs.com/)  
2. 系统选项选择Android  
3. 找到 `1.20.31` 或 `1.20.31.01`（我们也兼容 `1.20.30` ）  
4. 点击下载，如果无法访问就选择其他下载通道  
5. 安装 `.apk`  

</details>

<details>
<summary><strong>iOS</strong></summary>

## 登录

基岩版如果想要联机，必须登录XBOX账号（微软账号）  
如果你未登录，那么在游戏内左下角会显示登录按钮，点击后根据页面提示登录/注册即可，此处不过多赘述  

## 添加服务器  

1. 点击 **开始游戏** ，进入界面  
2. 点击 **服务器** ，进入服务器列表  
3. 点击 **添加服务器**  
4. 服务器名称任意，服务器地址填写群内获取的IP（去掉后面的冒号和端口号，端口就是后面那些数字），端口即填写IP地址后面的端口（不包括冒号）    

## 进入服务器

目前基岩版玩家可以免登录/注册，添加服务器完成后，只要没有其他问题，那么你就可以直接进入服务器了

地图请见[进入](./join#地图)
