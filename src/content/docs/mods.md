---
title: 服务端模组列表
description: 本服务器的服务端安装的模组列表
---

> ### 注意
>
> 这是服务端模组列表，客户端不需要完全一致，你可以不安装任何模组，也可以安装一些仅客户端的模组

以下为服务器当前启用的模组（不包含禁用的模组）：

| 模组名称 | 用途 |
| --- | --- |
| banhammer | 管理员惩罚工具，可对玩家进行临时/永久封禁、禁言或踢出 |
| BlueMap | 为服务器生成 3D 网页地图，可在浏览器中查看世界全貌 |
| c2me | 优化区块生成、I/O 和加载性能，提高多线程效率（并发区块管理引擎） |
| carpet-as-addition | Carpet 附加包，为假人添加 UI 高亮，便于与真实玩家区分 |
| carpet-extra | Carpet 扩展，增加新的发射器行为、可再生资源获取等特性 |
| chunksending | 优化服务端区块数据包的分发，优先发送近处区块，并分散到多个 tick |
| cupboard | 提供配置框架、崩溃追踪等功能的开发前置库 |
| easyauth | 离线服务器认证模组，禁止未认证玩家移动、放置方块等操作 |
| fabric-api | Fabric 模组基础 API，提供事件、钩子和注册工具 |
| fabric-carpet | 原版技术控制模组，可调整游戏机制、测试农场、放置假人等 |
| fabric-language-kotlin | Kotlin 语言支持库，让模组可以使用 Kotlin 开发 |
| fabric-permissions-api | 权限 API，让模组能够检查玩家的权限 |
| floodgate | 允许基岩版账号加入 Java 版服务器（Geyser 配套） |
| ForgeConfigAPIPort | 将 Forge/NeoForge 配置系统移植到 Fabric，方便模组移植 |
| geyser | Java 版与基岩版之间的协议转换代理 |
| gugle-carpet-addition | Carpet 附加包，增强假人管理和 BOT 功能 |
| hurricane | Geyser 官方辅助模组，修复基岩版玩家在 Java 服务器的各种体验问题 |
| ivan-carpet-addition | Carpet 扩展，提供技术向的工具和功能 |
| Jade | 显示玩家正在查看的方块/实体信息（WAILA 续作） |
| jei | 物品配方查看模组，按 R 键显示配方、U 键显示用途 |
| jline4mcdsrv | 服务器控制台增强，提供命令历史、自动补全和语法高亮 |
| JustEnoughResources | JEI 附属，查看生物掉落、箱子战利品、矿物分布等资源 |
| lazydfu | 延迟 DFU 初始化，加快游戏启动速度 |
| ledger | 服务器行为记录模组，可记录方块操作并支持回滚 |
| LuckPerms | 权限管理模组，通过组和权限控制玩家功能 |
| memoryleakfix | 修复客户端和服务端中的内存泄漏问题 |
| minimotd | 自定义服务器列表 MOTD，支持 RGB 颜色和渐变 |
| NoChatReports | 移除聊天加密签名，禁用聊天举报功能 |
| packetfixer | 修复各种数据包问题（如提高数据包大小上限，防止异常踢出） |
| skinrestorer | 离线服务器皮肤管理，可恢复和更换玩家皮肤 |
| starlight | 完全重写光照引擎，大幅提升光照性能 |
| TAB | 多功能信息显示模组，可自定义 Tab 列表、计分板等 |
| toofast | 移除服务器移动速度限制，避免 "moved too fast" 警告 |
| vanilla-permissions | 为原版命令添加权限检查，支持权限完全自定义 |
| vanish | 管理员隐身模组，使用 /vanish 完全消失不被发现 |
