## 启动器安装指南

<details>
<summary><strong> Android启动器</strong></summary>

- **推荐启动器**：FCL
- **下载地址**：[FCL GitHub Releases](https://github.com/FCL-Team/FoldCraftLauncher/releases)
- **安装步骤**：
  1. 使用浏览器打开网页，而不是在社交平台内（比如微信或者QQ）
  2. 下滑找到资源  
  3. 选择符合你的设备的APK安装包，如果不知道选择什么请直接下载FCL-release-版本号-all.apk  
  4. 由于服主并不使用Android设备，所以此处等待他人完善  
  5. 考虑到GitHub并不稳定，也可以前往[FCL 下载站](https://foldcraftlauncher.cn/html/down.html?id=0)下载

</details>

<details>
<summary><strong> 桌面启动器</strong></summary>

- **推荐启动器**：HMCL（Hello Minecraft! Launcher）或 PCL2（Plain Craft Launcher 2）
- **下载地址**：[HMCL 官网](https://hmcl.huangyuhui.net/) ｜ [PCL2 下载页](https://afdian.com/a/LTCat)
- **安装步骤**：
  1. 下载对应系统的安装包（Windows 为 .exe，macOS 为 .dmg）
  2. 安装后启动，选择游戏版本 1.20.1
  3. 在“多人游戏”中添加服务器地址
  4. 输入全局密码（群内获取）即可连接

</details>
